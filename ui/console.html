          Quickstart

          Three calls from sandbox key to verified webhook.

          HTTP · JSON
          01

          Create an intent

          curl -X POST "$BITOS_PAY_URL/v1/payment-intents" \
  -H "authorization: Bearer $BITOS_PAY_API_KEY" \
  -H "content-type: application/json" \
  -H "idempotency-key: order-1042" \
  -d '{"amount":12500,"currency":"SAT","scale":0,"payment_method":"lightning"}'
          02

          Read the intent

          curl "$BITOS_PAY_URL/v1/payment-intents/pi_..." \
  -H "authorization: Bearer $BITOS_PAY_API_KEY"

          Treat the invoice and payment hash as opaque strings.

          03

          Verify the webhook

          const signed = `${timestamp}.${rawBody}`;
const expected = hmacSha256(secret, signed);
// compare with BitOS-Pay-Signature: v1=...
// reject timestamps older than 5 minutes

          Verify before parsing, deduplicate by event id, return 2xx quickly.
